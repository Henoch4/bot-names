Why BotNames

Nobody should paste 42 characters into a chat window. Names are the layer addresses never got.

🔎

Instant resolve

resolve("alice") returns the owner address and expiry in one call — no indexer, no server, straight from the contract.

🔁

Transferable & renewable

Sell or gift a name with transferName; keep it alive with renew. Everything is a normal transaction.

⭐

Primary name

Set one label as your primary so wallets and dapps can show yourname.bot instead of 0x… everywhere.

How it works

Register, resolve, manage — all on-chain.

01

Register

Check availability, approve 0.1 TWBOT, call register(label). The label is yours for one year.

02

Resolve

Anyone calls resolve(label) → (owner, expires). Valid labels are hashed to a bytes32 key.

03

Manage

Renew before expiry, transfer to another address, or set your primary name — each one transaction.
