Validation rules

key      = keccak256(bytes(label))     // storage key
length   = 3…32 bytes
charset  = a-z 0-9 -                   // lowercase only
edges    = label[0] != '-' && label[len-1] != '-'
taken    = records[key].owner != 0  →  revert "Taken"
owner    = records[key].owner      →  expired ⇒ isAvailable() == true

Renewing an expired name re-activates it for the current owner; a live name can be transferred with transferName and surfaced with setPrimary.

Contract API
